# Study Pro — мобильное приложение (макет)

Кликабельный макет мобильного приложения платформы подготовки к ОГЭ и ЕГЭ для iOS и Android.
Собран на тех же технологиях, что и сайт, и открывается по ссылке в браузере — для
демонстрации до разработки нативного приложения.

**Демо:** https://bug1vuge.github.io/obrazovanie-app/ · **Сайт:**
https://bug1vuge.github.io/obrazovanie/

- На телефоне приложение занимает весь экран, учитывает вырезы экрана (safe area) и может быть
  добавлено на главный экран (PWA-манифест, иконки).
- На компьютере приложение показывается в рамке телефона, рядом — панель демо: переключение
  iOS / Android, тёмная тема, «Начать демо заново», ссылка на сайт.

## Что внутри

Весь функционал сайта перенесён в мобильный интерфейс:

| Раздел            | Что работает                                                                               |
| ----------------- | ------------------------------------------------------------------------------------------ |
| Первый запуск     | заставка, онбординг из трёх слайдов, вход (демо-аккаунты или e-mail), вход без регистрации |
| Каталог           | поиск, экзамен ОГЭ/ЕГЭ, предметы, сортировка (без цены и «Популярных»), уникальные обложки |
| Курс              | описание, программа, отзывы, пробный урок, запись, оплата в шторке с промокодом            |
| Обучение          | уроки, «Пройдено», содержание курса, тесты модулей, сертификат (PDF и печать)              |
| Кабинет ученика   | выбор ОГЭ/ЕГЭ и курса, прогресс, сертификаты                                               |
| Кабинет преподав. | курсы, конструктор курса (модули, уроки, тесты, модерация), статистика и доход             |
| Админ             | очередь модерации, статистика платформы, все курсы, предметы                               |
| Настройки         | профиль, тёмная тема, вид iOS/Android, сброс демо-данных, выход                            |

Нижняя навигация — «Каталог» и «Профиль», как на сайте.

Демо-аккаунты: ученик Алиса Смирнова, преподаватель Ирина Соколова, администратор. Промокоды:
`EGE2026` (−20%), `OGE15` (−15%), `START10` (−10%). Оплата имитируется.

## Нативные паттерны

- Стековая навигация: экран въезжает справа, «Назад» возвращает с обратной анимацией;
  позиция прокрутки каждого экрана запоминается.
- iOS: большие заголовки, сворачивающиеся в панель навигации, «‹ Назад», полупрозрачный таб-бар.
  Android: Material 3 — верхняя панель со стрелкой, навигационная панель с индикатором.
- Шторки снизу вместо модальных окон и выпадающих списков, закрываются свайпом вниз,
  тапом по фону или Escape; вложенные шторки закрываются по очереди.
- Тосты для уведомлений, переключатели, сгруппированные списки настроек, отклик на нажатие.

## Стек и архитектура

React 19, TypeScript (strict), Vite, React Router 7, Zustand 5, Tailwind CSS 3, Vitest +
Testing Library, ESLint, Prettier, GitHub Actions → GitHub Pages.

Доменная модель, стор, селекторы и демо-данные — те же, что на сайте (`entities`, `store`,
`data`), поэтому бизнес-логика одинакова на обеих платформах и покрыта теми же тестами.
Мобильный слой:

```
src/
  device/            рамка телефона, эмуляция статус-бара, выбор iOS/Android, корень оверлеев
  app/               роуты, стековая навигация с анимациями, таб-бар, онбординг
  screens/           экраны приложения
  shared/ui/native/  Screen, TabBar, Sheet, PickerField, ConfirmSheet, ListGroup, тосты
  widgets, features  блоки кабинетов и сценарии (оплата, тесты, отзывы, сертификат)
```

Данные хранятся в `localStorage` под своими ключами (`studypro-app-*`), отдельно от сайта.
